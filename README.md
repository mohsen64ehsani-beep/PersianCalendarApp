# روزنگار | PersianCalendarApp

اپلیکیشن اندرویدی تقویم هجری شمسی، تاریخ‌نگار و اوقات شرعی ایران.

## قابلیت‌های پیاده‌سازی‌شده در شاخه توسعه

- رابط فارسی و راست‌به‌چپ با صفحه اصلی بازطراحی‌شده
- نمایش تقویم ماهانه، هفتگی و سالانه
- انتخاب روز و نمایش معادل میلادی
- تبدیل دوطرفه تاریخ شمسی و میلادی با اعتبارسنجی تاریخ
- نمایش مناسبت‌ها و تعطیلات ثبت‌شده برای سال‌های ۱۴۰۵ و ۱۴۰۶
- ثبت رویداد شخصی و تنظیم اعلان یادآوری
- بازیابی یادآورها پس از راه‌اندازی مجدد و تغییر ساعت/منطقه زمانی دستگاه
- محاسبه آفلاین اوقات شرعی برای شهرهای منتخب ایران
- روش پیش‌فرض تهران با زاویه فجر ۱۷٫۷، مغرب ۴٫۵ و عشا ۱۴ درجه؛ امکان انتخاب روش‌های دیگر
- پنج رنگ اصلی، حالت تاریک و انتخاب فونت‌های پایه رابط
- ذخیره تنظیمات شهر، روش محاسبه، تم و حالت نمایش

## معماری و وابستگی‌ها

- Kotlin و Jetpack Compose
- Android ICU برای تقویم فارسی
- prayer-time-plus برای محاسبات نجومی اوقات شرعی
- AlarmManager و NotificationCompat برای یادآورها
- SharedPreferences برای تنظیمات سبک و رویدادهای محلی

## حریم خصوصی و دسترسی‌ها

- رویدادها و تنظیمات روی دستگاه نگهداری می‌شوند.
- اعلان‌ها فقط پس از درخواست مجوز اعلان Android 13 به بعد نمایش داده می‌شوند.
- یادآورها از setAndAllowWhileIdle استفاده می‌کنند؛ بنابراین زمان تحویل اعلان ممکن است تحت مدیریت باتری دستگاه کمی جابه‌جا شود.
- برنامه برای محاسبه تاریخ و اوقات شرعی به اتصال اینترنت نیاز ندارد.

## موارد باقی‌مانده پیش از انتشار

- افزودن و بسته‌بندی فونت‌های فارسی همراه برنامه با مجوز معتبر و انتخاب واقعی بین آن‌ها
- تکمیل پخش صوت اذان و تنظیم جداگانه اعلان هر نماز
- تکمیل و تطبیق همه مناسبت‌ها با فایل رسمی مرکز تقویم برای سال‌های بیشتر
- تکمیل آزمون‌های خودکار تاریخ، سال کبیسه، اوقات شرعی و یادآورها
- آزمون نهایی رابط روی اندازه‌های مختلف صفحه و نسخه‌های Android
- ساخت Release نهایی، بررسی امضای دیجیتال و آزمون نصب به‌روزرسانی

## ساخت و انتشار

ساخت APK فقط با اجرای دستی workflow در GitHub Actions انجام می‌شود تا در زمان توسعه نسخه‌های آزمایشی ناخواسته تولید نشوند. workflow ابتدا تست‌های واحد را اجرا می‌کند و سپس Release را با کلید انتشار موجود امضا و اعتبارسنجی می‌کند.
